## 🛠️ GitHub Pages 배포 설정

1. GitHub 저장소(`theties-studio/site`)의 **Settings** 이동
2. 좌측 메뉴의 **Pages** 클릭
3. **Build and deployment** > **Source** 항목을 `Deploy from a branch`로 설정
4. Branch를 `main` / `/(root)`로 지정 후 **Save** 저장
5. 잠시 후 `https://theties-studio.github.io/site/`로 서비스 배포 완료됩니다.
